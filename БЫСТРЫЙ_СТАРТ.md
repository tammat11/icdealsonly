# 🚀 Быстрый старт: Деплой на ic-group.kz/deals

## ✅ Что уже готово:
- ✅ Проект настроен для работы на `ic-group.kz/deals`
- ✅ Все изменения загружены на GitHub
- ✅ Готовы конфигурации для Nginx и Apache

## 📦 Шаги для деплоя:

### 1️⃣ Соберите проект

```bash
./deploy.sh
```

Или вручную:
```bash
npm run build
```

Это создаст папку `dist` с готовыми файлами.

### 2️⃣ Загрузите файлы на сервер

**Вариант А: Через FTP/SFTP клиент (FileZilla, Cyberduck)**
1. Подключитесь к `ic-group.kz`
2. Перейдите в корневую папку сайта (обычно `public_html` или `www`)
3. Создайте папку `deals` (если её нет)
4. Загрузите **содержимое** папки `dist` в папку `deals`

**Вариант Б: Через командную строку (SSH)**
```bash
# Подключитесь к серверу
ssh user@ic-group.kz

# Создайте папку (если нужно)
mkdir -p /var/www/ic-group.kz/deals

# Загрузите файлы (с вашего компьютера)
rsync -avz dist/ user@ic-group.kz:/var/www/ic-group.kz/deals/
```

### 3️⃣ Настройте веб-сервер

**Для Nginx:**
1. Скопируйте конфигурацию из файла `nginx.conf.example`
2. Добавьте её в `/etc/nginx/sites-available/ic-group.kz`
3. Перезапустите Nginx:
   ```bash
   sudo nginx -t
   sudo systemctl reload nginx
   ```

**Для Apache:**
1. Скопируйте файл `.htaccess.example` в папку `deals` на сервере
2. Переименуйте его в `.htaccess`

### 4️⃣ Настройте переменные окружения

На сервере создайте файл с переменными окружения или добавьте их в процесс сборки:

```bash
export VITE_BITRIX_WEBHOOK_URL="ваш_webhook_url"
npm run build
```

**Важно:** Переменные должны быть установлены **ДО** сборки проекта!

### 5️⃣ Проверьте сайт

Откройте в браузере: **https://ic-group.kz/deals**

---

## 📁 Структура на сервере должна быть:

```
/var/www/ic-group.kz/
├── index.html              (главная страница ic-group.kz)
├── другие файлы...
└── deals/                  ← ваш новый сайт
    ├── index.html
    ├── assets/
    │   ├── index-abc123.js
    │   ├── index-xyz789.css
    │   └── ...
    └── (другие файлы из dist)
```

## 🔄 Обновление сайта

Когда нужно обновить сайт:

1. Внесите изменения в код
2. Запустите `./deploy.sh` (или `npm run build`)
3. Загрузите новые файлы из `dist` на сервер в папку `deals`

## 🆘 Проблемы?

Если что-то не работает:

1. Проверьте права доступа к файлам: `chmod 644 файлы` и `chmod 755 папки`
2. Проверьте логи веб-сервера
3. Убедитесь, что базовый путь в `vite.config.ts` = `/deals/`
4. Проверьте, что все файлы из `dist` загружены на сервер
